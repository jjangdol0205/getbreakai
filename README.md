# 📈 1_RightSideAlpha_미국주식터미널 (`getbreakai.com`)

- **GitHub 원격 저장소**: `https://github.com/jjangdol0205/getbreakai`
- **GitHub Pages 주소**: `https://jjangdol0205.github.io/getbreakai/`
- **핵심 기능**: 미국 상장 72개 종목 폭락 후 우측 시동(Right-Side Ignition) 4팩터 스캐너 (`DD·LOW·MA·VOL`), 포지션 닥터(`-9% 칼손절 / 55일 시간손절 / +100% 원금회수`), 최신 종가 연동 리서치 브리프
- **로컬 서버 실행**: `python run_server.py` (`http://127.0.0.1:8000`)
- **전체 테스트**: `pytest backend/tests tests_e2e -q`
