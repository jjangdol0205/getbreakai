## 🚀 사용 방법

### 1. 대시보드 열람
- `D:\투자홈페이지\관심종목_백업_20261030\index.html` 파일을 더블 클릭하면 크롬, 엣지, 웨일 등 모든 브라우저에서 즉시 열립니다.
- 인터넷이 연결되지 않은 오프라인 환경에서도 100% 정상 작동합니다.

### 2. 주요 기능
- **종목별 필터링**: 전체, SK스퀘어, SK하이닉스, 우버, 모빌아이, 플루언스에너지, 업스타트 원클릭 조회
- **유형별 필터링**: 📊 일일 시세, 🎙️ 경영진 인터뷰, 📑 IB/공시, 🧠 투자 전략
- **실시간 키워드 검색**: `솔리다임`, `HBM`, `BCG`, `금리`, `가이던스` 등 입력 즉시 필터링
- **다크 / 라이트 모드**: 우측 상단 해/달 아이콘으로 전환
- **보유 포트폴리오 진단**: SK스퀘어(57.6%) / SK하이닉스(42.3%) 보유 비중 및 스위칭 가이드 상시 표시

### 3. 새로운 일일 브리핑 추가 방법 (2가지)
1. **화면에서 직접 추가**:
   - 우측 상단 `➕ 새 브리핑 추가` 버튼 클릭
   - AI가 브리핑해 준 내용을 복사·붙여넣기 후 `저장하기` 클릭 (브라우저 로컬 저장소에 영구 보존)
2. **`data.js` 파일에 직접 추가**:
   - `data.js`의 `records` 배열 맨 위에 새 항목 객체를 추가하면 영구적인 파일 기반 시계열 아카이브 완성!

### 4. 모바일 / 다른 기기에서 보는 팁
- `D:\투자홈페이지\관심종목_백업_20261030` 폴더를 Google Drive, OneDrive, 또는 개인 GitHub(비공개)에 동기화해 두시면 스마트폰이나 태블릿에서도 브라우저로 손쉽게 확인하실 수 있습니다.
